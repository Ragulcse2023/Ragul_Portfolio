# Ragul's Professional Portfolio

A modern, responsive portfolio website built with HTML5, CSS3, and JavaScript, deployed using GitHub Pages.

## 🌟 Features

- **Modern Design**: Clean and professional dark theme with gradient accents
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth scrolling, animations, and hover effects
- **Mobile Menu**: Hamburger navigation for mobile devices
- **Contact Form**: Functional contact section for inquiries
- **Social Links**: Quick links to social media profiles
- **Performance Optimized**: Fast loading and smooth animations

```
portfoli/

```

## 🚀 How to Deploy on GitHub Pages

### Step 1: Repository Settings
1. Go to your repository: `https://github.com/Ragulcse2023/portfoli`
2. Click on **Settings**
3. Scroll down to **GitHub Pages**
4. Select **Deploy from a branch**
5. Choose **main** branch and **/ (root)** folder
6. Click **Save**

### Step 2: Access Your Portfolio
Your portfolio will be live at: `https://Ragulcse2023.github.io/portfoli/`

## ✏️ Customization Guide

### Update Personal Information

**In `index.html`:**
- Line 40: Change name in hero section
- Line 73: Update email and contact info
- Line 165: Add your actual email
- Line 170: Add your phone number
- Line 175: Add your location

### Update Skills

**In `index.html` (Skills Section - lines 131-152):**
```html
<span class="skill-tag">Your Skill</span>
```

### Add/Modify Projects

**In `index.html` (Projects Section):**
- Duplicate a project card
- Update project title, description
- Change tech stack tags
- Update links to your projects

### Update Contact Information

**In `index.html` (Contact Section):**
- Email: Update `mailto:` link
- Phone: Update `tel:` link
- Social Links: Update URLs in hero section

### Customize Colors

**In `style.css`:**
Edit the CSS variables at the top:
```css
:root {
    --primary-color: #00d4ff;      /* Main accent color */
    --secondary-color: #0099ff;    /* Secondary color */
    --dark-bg: #0a0e27;            /* Dark background */
    --card-bg: #1a1f3a;            /* Card background */
    --text-light: #e0e0e0;         /* Light text */
    --text-dark: #b0b0b0;          /* Dark text */
}
```
